Excel มีแท็บ “วันนี้” เทียบ 2 แบรนด์ แท็บรายวันแยกแบรนด์ และข้อมูลดิบทั้งหมด · ดึงเข้า Google Sheets ได้ด้วยสูตร =IMPORTDATA("https://raw.githubusercontent.com/chasvitf/thai-oil-prices/main/data/daily.csv")

ทำงานอย่างไร

  1. ตั้งเวลาGitHub Actions รันเองทุกวัน 05:30 และ 19:00 น. ไม่ต้องเปิดคอมทิ้งไว้
  2. ดึงข้อมูลPython ขอราคาจากเว็บเซอร์วิสของ ปตท. และหน้าเว็บราคาน้ำมันของบางจาก แล้วจับคู่ชนิดน้ำมันที่ชื่อต่างกัน
  3. เก็บและส่งออกบันทึกลง CSV และสร้าง Excel ด้วย pandas เก็บประวัติทุกวันใน Git
  4. แจ้งเตือนถ้ามีประกาศราคาพรุ่งนี้ ส่งข้อความเข้า Telegram (หรือ LINE / อีเมล) ได้ทันที
